# RESTRICTED-AREA-ALERT-SYSTEM

##1.AIM:  
To design a simple alert system using an LDR, transistor, and buzzer to detect entry into a restricted area and produce an alarm.

##2\. Components Required:  
LDR (Light Dependent Resistor)  
Transistor (BC547)  
Buzzer  
Resistor  
Battery/DC power supply  
Connecting wires  
Breadboard

##3\. Problem Statement:  
Unauthorized entry into restricted areas can cause safety and security problems. A simple alert system is required to detect a change in light and immediately produce a buzzer sound.

##4\. Circuit Connection:  
The LDR and resistor form a voltage divider, whose output is connected to the base of the BC547 transistor. The buzzer is connected to the transistor's collector. When the light condition changes because the restricted path is interrupted, the transistor switches and activates the buzzer.

##5\. Working:  
1)The LDR continuously senses the surrounding light.  
2)Under normal conditions, the LDR provides a particular voltage to the transistor.  
3)When a person crosses the restricted area, the light falling on the LDR changes.  
4)This changes the voltage at the transistor's base.  
5)The transistor switches ON.  
6)The buzzer turns ON and gives an alert.  
7)Thus, unauthorized movement through the restricted area can be indicated by an audible alarm.

##6\. Applications:  
Restricted-entry areas  
Door and passage monitoring  
Security systems  
Laboratory areas  
Store rooms  
Simple intrusion-alert systems

##7\. Advantages:  
Simple and low-cost  
Easy to construct  
Requires few components  
Provides immediate audio indication  
Suitable for mini-projects

##8\. Result:  
The Restricted Area Alert System was successfully designed using an LDR, transistor, and buzzer. The system detects a change in light and activates the buzzer to indicate movement through the restricted area.
